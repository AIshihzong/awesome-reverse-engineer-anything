# 真的用了 REA 吗？

[English](is-it-rea.md) · **简体中文**

很多案例都写着"用 REA 做的"。这一页把每个案例和项目自己的 README、作者帖子或官方案例逐一对照，并记录结果。核对日期为 2026-10-14。我们的环境无法打开 X 帖子，所以对于 X 上的案例，我们依据的是表格里注明的第三方案例记录。
